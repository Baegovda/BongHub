# BongHub 변경 이력

## 3.3.6 (2026-11-01)
- 이미지 전체 순회 대신 클릭 근처 객체만 검색하고 선택 해제를 먼저 처리
- 글씨 메뉴에 텍스트·제목1(24pt)·제목2(20pt)·제목3(16pt)·제목4(13pt) 추가
- 그림자 없이 상단에서 본문으로 이어지는 색상 그라데이션 복원

## 3.3.5 (2026-11-01)
- 이미지 RTF 분석·객체 위치 목록·DPI 캐시로 드래그 중 반복 추출 제거, 이동 중 중간 화면 다시 그리기 억제
- 메모 상단과 본문을 동일한 평면 색상으로 통일
- RichEdit 기본 커서 처리와 사용자 지정 커서의 충돌 제거
- 메모 크기 조절 중 스냅샷 대신 실제 본문과 줄바꿈을 즉시 갱신

## 3.3.4 (2026-11-01)
- 스티커 메모의 첨부 이미지 위에서 드래그해 본문 안 다른 위치로 이동. 놓을 위치 표시와 이동 커서 추가
- 글씨 도구막대에 작게·보통·크게 빠른 크기 선택 추가
- 메모 색상 팔레트에 호버 미리보기 추가: 포인터가 벗어나면 원래 색으로 돌아가고 클릭해야 저장
- 채도와 명도를 낮춘 색상 18개 추가
- 이미지 크기 조절 커서를 안정화하고 메모 창의 가장자리 크기 조절 영역을 넓힘
- 이미지 더블클릭 뷰어에서 제목 표시줄과 작업 표시줄 항목을 숨기고 얇은 맞춤 테두리 유지
- 앱 모달 창이 떠 있어도 메모 창을 다시 활성화하고 선택할 수 있게 함
- 입력 중 파일 저장으로 타이핑이 끊기지 않도록 자동 저장을 마지막 입력 1.8초 뒤로 미룸

## 3.3.3 (2026-10-31)
- 창 크기를 끄는 동안 직전 화면을 확대하지 않음. 글자, 사이드바, 목록, 카드는 원래 픽셀 크기(1:1)로 왼쪽 위에 두고, 줄어들면 그 자리에서 잘라 냄
- 늘어난 영역은 창 배경색으로 채움. 제목 표시줄 단추는 오른쪽 끝에, 스티커 메모 하단 도구막대는 아래쪽 끝에 붙임
- 버튼을 놓으면 한 번만 실제 배치 (설정, 스티커 메모, 이미지 보기, 창 고르기)

## 3.3.2 (2026-10-31)
- 설정 창, 스티커 메모, 이미지 보기, 창 고르기처럼 크기를 조절하는 창: 테두리를 끄는 동안에는 레이아웃과 그라데이션을 픽셀마다 다시 계산하지 않고, 직전 화면을 새 크기에 맞춰 늘려 보여 줌
- 마우스 버튼을 놓으면 그때 한 번만 실제 배치·다시 그리기 (리치 텍스트 줄바꿈, 설정 카드, 목록 열 너비 포함)
- 메모 면, 설정 카드, 사이드바, 제목 표시줄 그라데이션은 크기나 색이 바뀔 때만 비트맵으로 다시 만들고, 그 사이에는 그 비트맵을 그림

## 3.3.1 (2026-10-31)
- 모니터 프리셋 편집에 '창 배치(작업 영역)' 드롭다운 추가 (저장된 작업 영역 + '연계 안 함')
- 프리셋 전환이 끝나면(화면 안정 → 밝기 → 아이콘 배치 복원 직후, 오버레이가 닫히기 전) 연계된 작업 영역을 정확히 한 번 실행·배치
- 이미 열린 앱은 옮기기만 하고, 없는 앱은 작업 영역의 '자동 실행' 설정을 따름
- 중복 실행 방지(프로세스 간 뮤텍스 + 10초 스탬프, 명령줄 전환 포함), 삭제된 작업 영역은 ⚠ 안내와 알림, 실패해도 전환은 계속되고 상태 표시
- 기존 설정 호환(연계 없음으로 이전), 즉시 저장

## 3.3.0 (2026-10-31)
- FancyZones: 영역 편집기(클릭 나누기·Shift+클릭 가로 나누기·오른쪽 클릭 두 번 합치기 → 캔버스 레이아웃), Ctrl+드래그 여러 영역 걸치기, Shift 없이 항상 표시 옵션(Shift로 반전), Win+←/→ 영역 이동(다음 모니터까지, 기본 꺼짐), 끌어낼 때 원래 크기 복원, 모든 모니터 표시, 영역 색·강조 색·불투명도·번호, 제외 앱 목록
- 잡아서 이동: 후킹 콜백은 즉시 반환, 창 이동은 전용 스레드에서 합쳐서 처리
- 작업 영역: 이미 열린 창 옮기기/새로 실행 선택, 바탕화면 바로 가기, `BongHub.exe workspace <이름>` 명령
- 명령 팔레트: 백그라운드 앱 색인(시작 메뉴+스토어 앱), 단어 첫 글자 검색, 수식 계산기(^ sqrt sin log hex…), 단위 변환(길이·무게·부피·데이터·시간·속도·넓이·온도·평), 시간/세계 시각, 창 전환(<), 파일 검색(?), 명령 실행(>), 웹 검색(??), Windows 터미널 프로필, 시스템 명령(확인 후), Windows 설정 페이지, 창 재사용
- 고급 붙여넣기: 사용자 지정 동작(정규식·템플릿·대/소문자·정렬·중복 제거·URL/Base64), .txt/.html/.png/.jpg 파일로 붙여넣기, JSON/마크다운 바로 붙여넣기 단축키
- 미리보기: 여러 파일 ←/→ 이동, 코드 구문 강조, 마크다운·HTML 렌더링(스크립트 차단), GIF 애니메이션, WebP/HEIC 썸네일, 동영상/음악, ZIP 목록, 폴더, PDF/Office(설치된 미리보기 처리기), 포커스 잃으면 닫기 옵션, 내용 지연 로딩
- Image Resizer: Windows 이미징(WIC) 엔진, 병렬 처리, JPEG 축소 디코딩, %·cm·in 단위, 사용자 지정 크기, 파일 이름 형식(%1~%6), 사진 방향 무시, 메타데이터 유지/제거, 수정 날짜 유지, 기타 형식 대체 저장
- 최적화: 영역 계산 캐시(디스플레이 변경 시 무효화), 오버레이 비트맵 캐시·부분 다시 그리기, 꺼진 기능은 코드 경로 자체를 건드리지 않음

## 3.2.0 (2026-10-31)
- 새 PowerToys 탭: 기능 카드 그리드(아이콘·설명·즉시 토글·상태 배지), 카드별 상세 화면(뒤로 가기), 기능 검색, 단축키 충돌 표시
- FancyZones: 모니터별 레이아웃(열/행/격자/가운데 강조/직접 비율), Shift+드래그 스냅, 창 위치 규칙의 'FancyZones 영역에 맞춤' 동작
- 잡아서 이동: 보조 키(Alt/Win/Ctrl+Alt)+왼쪽 드래그 이동, +오른쪽 드래그 크기 조정
- 작업 영역: 열린 앱·위치·모니터·상태 저장, 없는 앱 실행 후 배치, 작업 영역별 단축키
- 명령 팔레트(Ctrl+Alt+Space): 앱·BongHub 명령·메모·작업 영역·아이콘 배치·계산·웹 검색
- 고급 붙여넣기(Ctrl+Alt+V / 서식 없이 Ctrl+Alt+Shift+V): 텍스트·마크다운·JSON·공백 정리·이미지→PNG
- 미리보기(Ctrl+Shift+Space): 탐색기 선택 파일의 이미지·텍스트·정보
- Image Resizer: 끌어 놓기 일괄 변환, 프리셋, 맞춤/채우기/늘이기, 줄이기만, JPEG 품질, 선택형 탐색기 우클릭 메뉴(HKCU)
- 위험 기능(전역 후킹·창 끌기·탐색기 연동)은 기본 꺼짐, 꺼진 기능은 후킹·타이머 0
- 정보 탭에 Microsoft PowerToys(MIT) 고지
- 전환 오버레이: 가운데 아이콘 떨림 수정(아이콘을 한 번만 정수 크기로 렌더, 중심 좌표 정수 고정, 매 프레임 확대/축소 제거, 주 모니터 좌표가 안정될 때만 재배치)
- 모니터 프리셋별 밝기(전체/모니터별, 0~100%, 변경 안 함): DDC/CI → VCP 0x10 → WMI(노트북) 순서, 모니터가 켜질 때까지 재시도, 실패해도 전환 계속·상태 표시
- 모니터 프리셋별 바탕화면 아이콘 배치 연계: 전환 후 화면이 안정되면 한 번만 복원, 자동 복원과 중복 방지, 삭제된 배치 안내

## 3.1.0 (2026-10-31)
- 유휴 CPU 최적화: 창 위치 유지 감시에서 시스템 전체 위치 변경 이벤트 제거, 점검 주기 5초→15초
- 스티커 메모: 타이틀바와 본문을 하나의 그라데이션 면으로 연결
- 얇은 오버레이 스크롤바(메모 본문, 설정 페이지, 목록)
- 메모 이미지: 클릭 선택 + 핸들 리사이즈(비율 고정, Shift 자유), 크기 툴팁, 우클릭 메뉴(복사/25·50·75·100%/폭 맞춤/원본/삭제), Delete 삭제, 더블클릭 이미지 뷰어(휠 확대·드래그 이동·맞춤/100%)
- 확인/입력 창도 커스텀 타이틀바
- 버전 표시(정보 탭, exe 파일 정보), 구성 요소 버전, 클라우드 데이터 형식 버전 보호
