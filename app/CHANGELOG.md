# BongHub 변경 이력

## 3.4.6 (2026-11-01)
- 새 스티커 메모를 만들 때 팔레트에서 무작위 색상을 배정하고 기본색과 겹치지 않게 변경
- 제목 영역과 본문 입력칸의 구분선·별도 면을 없애 하나의 평평한 판처럼 보이도록 정리
- 선택한 이미지를 Ctrl+C로 누르면 `[image]` 텍스트가 아닌 실제 이미지 데이터를 클립보드에 복사
- 텍스트 범위에 이미지를 함께 선택하고 끌 수 있도록 RichEdit 혼합 선택과 자동 드래그 허용
- 이미지 크기 조절 중 고속 미리보기 레이어를 실시간 갱신하고 놓을 때 RTF를 한 번만 변경
- 이미지 RTF 메타데이터 분석에서 대용량 16진수 본문 복사를 제거하고, 크기 조절 뒤 휠 스크롤에서도 선택 유지
- 본문보다 큰 이미지의 조절점을 보이는 영역 안에 유지하고 링크 위에서 손가락 커서 표시
- 이미지 이동 중 현재 안착할 텍스트 위치를 삽입선으로 표시
- Sysinternals Autologon이 거부하는 로컬 무암호 계정용 부팅 자동 로그인 설정과 원상복원 추가
- 메모 위쪽에 핀·글자 크기·색상·최근 메모 목록 버튼을 항상 표시하고 중복 `⋯` 버튼 제거

## 3.4.5 (2026-11-01)
- 이 PC에서 보이지 않는 Windows 로그인 옵션 문구를 제거하고, 활성 전원 계획의 절전 복귀 인증 요구(AC/DC)를 관리자 권한으로 직접 적용·원상복원하도록 변경
- 이미지 보기 창 종료 뒤 남은 확대 애니메이션 타이머가 폐기된 이미지를 읽으며 예외를 띄우던 문제 수정

## 3.4.4 (2026-11-01)
- 일반 설정에 Windows 절전 복귀 로그인 옵션과 Microsoft Autologon 공식 안내 바로가기 추가
- 부팅 자동 로그인에 필요한 계정 암호는 Microsoft 도구에서 직접 입력하도록 안내
- 로그인 설정이나 자격 증명을 앱에서 자동 변경·수집하지 않는 공식 설정 연결 방식

## 3.4.3 (2026-11-01)
- 잡아서 이동에서 대상 창에 비동기 위치 메시지가 쌓이지 않도록 완료 기준으로 최신 좌표만 전달
- 이동 중 마우스 이동 이벤트 소비, 올바른 버튼 해제 시 최종 좌표 반영, 다른 버튼 해제로 중단되는 문제 수정
- 최대화 창은 실제 드래그 시작 시 복원하고 창별 최소·최대 크기를 존중하며 반대편 가장자리 고정
- PowerToys 모든 상세 설정에서 마우스 뒤로가기 및 드라이버 Browser Back 명령으로 목록 복귀
- 탐색기 Space 미리보기를 누르는 동안만 표시, 자동 반복 방지 및 해제 후 지연 조회 결과 취소
- 공식 libwebp 1.6.0 디코더로 WebP 표시 (손실·무손실·투명도, 애니메이션은 첫 프레임)
- WebP는 별도 작업에서 읽어 Space 해제 시 창을 바로 닫고, 닫힌 창에 늦게 도착한 이미지 폐기
- 실제 후킹·외부 창 이동 없이 느린 대상·버튼 상태·음수 좌표·네 모서리·뒤로가기·WebP 회귀 검사

## 3.4.2 (2026-11-01)

- 레이아웃 선호 크기 측정 캐시 및 열 너비 계산 정리, 중복 너비 제약 갱신 배치
- 실제 컨트롤을 유지한 채 크기 조절 요청을 프레임 단위로 병합하고 마지막 크기는 즉시 반영
- 크기 조절 중 배경 비트맵 반복 할당 방지, 설정 내부의 불필요한 투명 배경 합성 제거
- 첫 페이지 표시 뒤 나머지 탭을 순차 준비하고 드래그 중에는 준비 중지
- 숨은 데스크톱 탭 전환·연속 크기 변경 진단 추가

- 관리자 권한 앱 조작을 위한 명시적인 관리자 권한 재시작 버튼 추가
- 설정 창을 열어도 기능 단축키를 유지하고 저장 즉시 재등록
- 미리보기 선택 파일 취득을 STA 스레드로 분리, 탐색기·바탕화면 선택 지원 및 COM 정리, 직접 파일 선택 미리보기 추가
- 공식 단축키 기본값: 명령 팔레트 Win+Alt+Space, 고급 붙여넣기 Win+Shift+V, 서식 없이 Ctrl+Win+Alt+V, 미리보기 Space(탐색기 비입력 상태에서만 동작)
- 기존 기본 단축키만 이전하며 사용자 지정은 보존
